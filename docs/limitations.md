# Limitations

This purposive 13-drug set is not exhaustive and over-represents mechanisms discussed in the source. Evidence availability and selection create knowledge-base bias. One principal disease context per drug simplifies agents with many indications. Regulatory status may change after the verification date and differs by jurisdiction. Pathway annotations are broad, descriptive systems rather than full Reactome event hierarchies. The graph is undirected for descriptive analysis and does not model dose, temporal signaling, tissue expression or causal effect. Degree reflects curation choices. Trial heterogeneity precludes indirect efficacy ranking or meta-analysis. No individual treatment inference should be made from these data.
